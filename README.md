# Student Expense Tracker

A beginner-friendly, console-based Python project for recording expenses and checking them against a monthly budget.

## Features

- Enter a monthly budget.
- Add expenses with a category and amount.
- View expenses recorded during the current run.
- See the total spent and remaining budget.
- Get a warning when expenses exceed the budget.

## Requirements

- Python 3
- No third-party packages

## Run the project

Open a terminal in this folder and run:

```bash
python3 EXPENSE1.PY
```

Follow the menu prompts to use the tracker. The menu can repeat up to 100 times and exits when option 4 is selected.

## Notes

- This version uses beginner Python concepts, including lists, `for` loops, and `if` / `elif` / `else` statements.
- It does not use a `while` loop or `import os`.
- Expenses are stored in memory only, so they are cleared when the program closes.
- Enter numeric values for the budget, menu choice, and expense amount.
